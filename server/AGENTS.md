# Agent server

`server/` is Hamlet's TypeScript agent server, running on Node 24 and
pi-durable. Follow the root [`AGENTS.md`](../AGENTS.md) for checks and safe
running.

## Project standards

- Read [`docs/coding-standards.md`](docs/coding-standards.md) before writing
  or reviewing server code. Check finished code against it before calling
  the work done.
- Read [`docs/errors.md`](docs/errors.md) before adding or changing an
  error, an error message or retry advice.
